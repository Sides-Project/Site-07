Об Участке-07

FILE // S07-OVR-2000

> ОБЩАЯ ИНФОРМАЦИЯ

Участок-07 представляет собой складское учреждение низкого уровня, предназначенное для хранения экспериментальных объектов, а также для временного размещения аномальных объектов.

Участок является действующим и функционирует в штатном режиме, обеспечивая хранение, содержание и временное размещение объектов в соответствии с установленными протоколами безопасности.

Профиль Участка-07

Участок-07 — действующее складское учреждение низкого уровня Фонда SCP, расположенное в Вильяндимаа, Эстония.

Учреждение предназначено для хранения экспериментальных объектов, временного размещения аномальных объектов, а также их содержания в соответствии с установленными протоколами безопасности.
