01 // FACILITY OVERVIEW

О Site-07

FILE // S07-OVR-2000

> ОБЩАЯ ИНФОРМАЦИЯ

Site-07 является складским и логистическим комплексом Фонда SCP, предназначенным для хранения и временного содержания аномальных объектов.

На территории комплекса также хранится и тестируется экспериментальное оружие.

02 // ARCHIVED RECORDS

История объекта

TIMELINE // VERIFIED

АРХИВ

Site-19 и Site-02

Первоначально существовали две зоны — Site-19 и Site-02. После атаки Повстанцев Хаоса Site-19 был захвачен и исчез с радаров. Его дальнейшая судьба неизвестна.

RECORD 02

Переименование

После исчезновения Site-19 Совет Зоны принял решение переименовать оставшийся Site-02 в Site-07. Так появился нынешний объект.

CURRENT

Текущая оперативная сводка

В истории комплекса отмечены отражённая атака Повстанцев Хаоса, попытки взлома, нарушения безопасности и другие инциденты.
